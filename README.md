# Сервис назначения ревьюеров для Pull Request'ов

## Обзор проекта

Сервис автоматического назначения ревьюеров для Pull Request'ов, который позволяет выполнять переназначение ревьюверов и получать список PR’ов, назначенных конкретному пользователю, а также управлять командами и активностью пользователей.

## Реализованный функционал

- **Управление Pull Request'ами:**

  - Автоматическое назначение до двух активных ревьюверов из команды автора при создании PR (исключая самого автора)

  - Переназначение ревьюверов с заменой на случайного активного участника из команды заменяемого

  - Получение списка всех PR'ов, назначенных конкретному пользователю

  - Идемпотентная операция merge PR с защитой от изменений после слияния

- **Управление командами и пользователями:**

  - Создание и управление командами разработчиков

  - Управление флагом активности пользователей (isActive)

  - Массовая деактивация пользователей команды

  - Автоматическая блокировка назначений неактивных пользователей на ревью

- **Аналитика:**

  - Эндпоинт статистики с информацией о количестве назначений по пользователям и по PR

## Принятые проектные решения

- Флаг активности влияет только на выбор ревьюверов и reassignment, а автор PR может быть как активным, так и неактивным.​
- При деактивации пользователя, который назначен ревьювером в открытых PR, попытаться переназначить его на другого активного пользователя, а если кандидатов нет — просто убрать его из списка ревьюверов.

Изменения в OpenAPI:

- Добавлены коды ошибок 400 Bad Request и 500 Internal Server Error для всех эндпоинтов.
- В схему ErrorResponse в поле code добавлены новые значения:
  - INVALID_INPUT - для ошибок валидации (400).
  - INTERNAL_ERROR - для непредвиденных ошибок сервера (500).
- format: uuid для всех полей с id.
- В примерах простые id заменены на uuid.
- Добавлены ограничения minLength и maxLength для имен, чтобы исключить пустые строки или слишком длинные названия.
- Добавлен эндпоинт /health.
- Добавлены поля operationId, чтобы сгенерировались красивые имена методов.
- Код для ошибки team already exists изменен на 409.
- Добавлен ответ 404 для /users/getReview.
- Добавлены эндпоинты статистики и деактивации.
- у /pullRequest/reassign в примере old_reviewer_id заменен на old_user_id (так и должно быть)
